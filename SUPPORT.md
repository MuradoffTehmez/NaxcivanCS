# Dəstək

Əvvəlcə [quraşdırma](docs/wiki/Installation.md), [problemlərin həlli](docs/wiki/Troubleshooting.md) və [məlum problemlər](docs/KNOWN_ISSUES.md) bölmələrinə baxın.

Adi bug və funksiya təklifi üçün [GitHub Issues](https://github.com/MuradoffTehmez/NaxcivanCS/issues) istifadə edin. Təcili cavab və ya xidmət səviyyəsi zəmanəti yoxdur.

Hesabatda bunları göstərin:

- Git teqi və `git rev-parse HEAD` nəticəsi.
- Əməliyyat sistemi, Godot .NET versiyası, .NET SDK/runtime.
- Server və client-in necə başladıldığı; lokal və ya LAN olması.
- Təkrar yaratma addımları, gözlənilən və faktiki nəticə.
- Uyğun log hissəsi; lazım olsa görüntü və test müddəti.

Parol, token və şəxsi məlumatları silin. Təhlükəsizlik problemi üçün [SECURITY.md](SECURITY.md) qaydasını izləyin. Headless smoke testin keçməsi render, səs və competitive balansın təsdiqi deyil.
